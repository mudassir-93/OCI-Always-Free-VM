# Claude Code project instructions

Before any work, read AGENTS.md and PROJECT_CONTEXT.md. They are the canonical project rules and durable context.

Follow docs/AGENT_WORKFLOW.md for planning, implementation, validation, review, and final reporting. Do not duplicate or override the safety rules here.
